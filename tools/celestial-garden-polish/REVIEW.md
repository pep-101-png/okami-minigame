# Celestial garden, catalogue and farm follow-up

Desktop baseline: 931b4ab97a77685802f6dcbcef3c5ba9924e3611. Existing playable Windflower and the waterfall transfer remain the target. No new demo scene or in-game trailer.

Changes:
- All fifteen catalogue portraits now use the original encrypted `data_pc/id/weapon/ama_01.dds` through `ama_15.dds` equipment illustrations, decrypted and converted to full 1024x1024 RGBA PNGs. The original art shows Amaterasu equipped with each corresponding weapon; ordering matches reflector/glaive/rosary IDs. No invented artwork, diagnostic mesh renders or recolouring. Portrait area increased to 300 pixels.
- Festival race is 50 seconds, retaining thirteen checkpoints and existing reward prices.
- Farm cleanup disables eighteen rock/bamboo render objects overlapping pens, eight stale placement footprints, five old navigation obstacle records and one obsolete physical trunk/rock capsule. Original thirteen-animal population still includes two roosters. Animals retry clear locations inside their own yard if an old spawn point is blocked; this does not move them across pens or delete gameplay collision globally.
- Heavenly garden uses a resource-backed layout of more than 350 original models: original meadow/terrace source surfaces, carved stone paths, standing torii, full sacred stone bridge, a shrine backdrop, complete original enclosed ponds, original pine paintings, lilies/irises/hydrangeas, stone lanterns, core spirit sprites and original cloud art. The old giant flattened VT28 rock floor, disconnected water effect shapes, partial gate/wooden stage and arbitrary toy-cat altar are not used in the new layout.
- Cloud-painted sky has a warm/blue pearl palette. Native thin-tree paintings face the camera; pond water is masked within its original rocky rim. Original spirit artwork forms three soft light shafts and drifting lights/petals. Source texture pixels remain original; Sunward shader, placement and particle adapters provide the new composition, not a claimed recovery of an original stage/event interpreter.
- Garden fades in the existing quiet original melodic passage (BGM bank stream 67) and fades out village music/river ambience. This is not an identified Celestial Plain soundtrack or a verified somber composition; audible mood and mix need listening review.

Bark research: correctly decrypted additional PL0D and AN05/AN11/AN18 sound banks. AN05/AN11/AN18 share their short canine clips. Three separate audition WAVs were published because inline audio players were not visible. Event names are unlabelled. The user rejected these as previously heard soft puppy barks. Do not offer them again. A decoded PCM comparison also found PL0D-40/41 very similar to PL00-40/41, so these are excluded as replacements. Further research decoded the two separate PL00 AFS2 player archive streams and the distinct PL0D-16 vocal, with event identity still unverified. Until a suitable replacement is identified, the currently installed PL00-41 bark remains unchanged; do not report the bark as replaced or subjectively approved.

Inspection: four offline views are generated from the same runtime placement JSON and original models, paint and effect sprites. Initial inspection found ground gaps, a sideways gate, edge-on tree paintings, square water edges and a misidentified toy-cat prop. These were corrected before packaging. Offline views omit live NPC motion and approximate particles; they are not Unity screenshots, physics proof, shader compilation or visual approval from the user. No claim of perfection is justified without the running game.

Validation: selected actual runtime scripts compile against .NET engine doubles with zero errors. 13 festival, 23 village, 38 garden/race/collapse (including actual 50-second expiry), 336 native text layout and 915 boss/director checks pass. Native source/layout verification samples the actual ground triangles around 96 points of the guarded perimeter and arrival/keeper/visitor locations. Metadata and native resource links are audited. Existing native garden, farm/audio and doorway checks are rerun after catalogue size updates. There is no Unity Editor in this workspace, so actual game performance, rendering, bird spawning, sound, shader compilation and route feel remain unverified.

Only changed Assets/.meta files go in the game ZIP; review documents, tools, images, bark auditions and raw source archives stay out. The PR stays stacked on the working Desktop lineage, rather than merging the whole remaster over the old integration project.
