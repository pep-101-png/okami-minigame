# Sunward combat, interiors and lower arena — 31 October 2026

This updates the existing Windflower game, not a demonstration scene. Source rollback is `1a47fd212f238f7cfa54eea5cc82c63481ddcb9b`, branch `backup/before-combat-depths-20261031`. Only original Ōkami media are used. Sunward code adapts native geometry to the existing layout, schedules original motion curves, controls collision and lights/emission, and attenuates original sound. It does not reproduce the complete original game engine.

## Latest playtest list: implemented changes

- **Walking and jumping:** halved playback gain again: step .045→.0225 and jump .35→.175. Added an airborne-time/landing-speed guard so momentary capsule contact loss on terrain cannot repeatedly play landing audio while walking.
- **Swimming sound:** water cue gain .75→.035 and slower repeat interval, preserving the original recording. No synthesis or pitch changes.
- **Swimming motion:** removed the rejected land cycle 013. Idle/forward swimming now use original looping water-family candidates `pl00_130`/`pl00_131`, with raised muzzle/neck and submerged alternating leg strokes, using their original pose curves and a swimming cadence. Full-cycle source pose sheets and SHA-256 provenance are included. Their symbolic native action names are not present in the supplied data; **Unity swimming acceptance is unverified**. This is a real source-clip replacement, not another retiming of 013/01d/01e.
- **Home:** replaced the misidentified loom with a confirmed original VT90 cabinet, added two matching supported weapon cabinets, a native low game/tea table, cup and paper screens. Replaced the black interior slab's artwork with original wood/tatami. Aligned the actual visible weapon-part bounds to the cabinet tops, accounting for hidden effect meshes that inflated old bounds. Moved all six collectible slots onto the cabinet top and kept their runtime contents hidden outside. Disabled the duplicate legacy Solar Flare wall cradle and old floating cup/loom. Removed outdoor vegetation from the floor footprint. New furnishing collision uses the original model meshes.
- **Shrine/torii in front of dojo:** removed all four original offering-shrine objects. Removed its invisible interaction target too. The existing three-windflower vitality blessing remains available through the home memory mirror; its saved flag and rewards are preserved.
- **Dojo:** rotated all native interior geometry and each training pair 180 degrees around the same pivot. Matched all six trainee/dummy roots to the actual mesh surface. The native floor has slopes/bevels; player support now raycasts the real floor instead of assuming two constant heights. The inside entry moved to .82 above the measured .80 ramp, avoiding teleporting into it. Exit interaction remains available inside.
- **Markets:** retained the larger successful stalls, turned them inward toward the street, repositioned merchants behind their counters at X=±8.6/Z=0, and moved the actual purchase prompts and counter collisions with them. The fixed station override still prevents safe-spawn navigation displacing merchants.
- **All fifteen weapons:** reviewed source groups individually. Restored missing complete blades for Seven Strike/Kusanagi/Eighth Wonder/Thunder Edge, all three Trinity Mirror plates and missing rosary parts. Tundra Beads now displays the twelve blue bead parts instead of only its snowflake effect. Model-group selections and original MD hashes are recorded in `weapon-model-audit.json`.
- **Combat playback:** all fifteen instruments use one native weapon-view path; no separate legacy spear/disc renderer is instantiated. Glaives/reflectors use their native dorsal attachment and original PL attack family. Rosary whip motions follow the same normalized attack clock as the body, including charge/air actions, and stop cleanly on cancellation. Increased weapon/enemy skin culling bounds to prevent long swings/rosaries disappearing. Body action duration comes from the native motion rather than the old improvised clip length. Added six-stage rosary light chains and family-specific original light/heavy/charge/air actions, including native family poses during charge holds. Existing ownership, shop prices, saves, upgrades, damage scaling and enemy statistics remain in use; motion timing, attack cadence/ranges/arcs and lunge are intentional combat changes. Hit windows now survive a frame stepping across the entire active interval.
- **Weapon audio:** added thirty bindings from each instrument's own original SES bank, rather than using the generic glaive attack sound for every weapon. Original ADX decryption, attenuation, DC removal and edge fades only; output peaks/hashes checked. Exact original event-to-stream dispatch is not recovered; the selected numbered cue assignments require audible playtesting. Enemy attack/impact feedback is positional and quiet.
- **All six existing enemy prefabs:** own-archive variant actions replace the provisional shared attack: green/instrument `em00_082`, paper `em00_181`, drum `em00_152`, flute/staff `em00_052`, elite `em00_194`. Crimson Helm selects `em65_022`/021/023 for charge/slam/ranged moves. Existing source models/paint, health, rewards and waves remain. Native attack sections have enough time to play; original charge travel remains capped independently of animation length.
- **Lower arena:** a roughly 62 m chamber, about three times the upper arena's area, 20 m below it. Built from original stage floor/wood/tatami/stone artwork, original stone models, twelve lanterns, four stone corner ornaments and crystal clusters. ## What remains unverified or incomplete

No Unity editor or remote control of the user's PC is available here. **Compilation, actual playability, all fifteen weapon purchases/switches/attacks, swimming appearance and sound balance are unverified in Unity.** Latest published PC feedback is still the older 21 October build (`aefd595…`), with incomplete/unreviewed capture coverage; it cannot validate this source.

The original EST/SEQ combat/effect event interpreter and exact native sound dispatch are not fully reconstructed. This uses original models, textures, waveform data and skeletal curves with Sunward adapters; it is not a complete byte-identical reproduction of Ōkami combat/effects. Do not describe that missing engine work as finished. Symbolic swimming action names are absent. The earlier village/pub music identification and dedicated koto finger-playing motion also remain unresolved; town/pub music stays silent rather than using the wrong battle/jingle track. Original UI font port remains unfinished.
