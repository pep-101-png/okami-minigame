# Archived reference and research inputs

These files supported the former separate review scene. They are outside Unity's Assets folder and are not another playable demonstration or runtime dependency. The actual modified game scene is Assets/Sunward/Scenes/Windflower.unity.

DemoGeometry and DemoMaterials are authoring inputs for tools/remaster/live/apply_windflower.py. DemoScripts/DemoScenes/Editor preserve the earlier review tooling for provenance, not installation. NativeSources preserves the 165 original Ammy MOT payloads, default skin and Solar Flare research assets for the remaining animation/effects integration. They are not active gameplay replacements.

Source geometry, source material metadata and original motion/component bytes were retained. The original separate project and the prior review stage also remain recoverable from Git history. Shared painted textures, shaders and native animal resources that the actual game uses remain under Assets/OkamiRemaster/Village.
