SUNWARD — RIVER & LANTERNS

1. Extract this ZIP into a NEW folder, separate from your existing synced project.
2. In Unity Hub choose Add > Add project from disk.
3. Select the extracted Sunward-Unity folder and open with Unity 6000.6.6f1.
4. Let Unity finish its first import, then open Assets/Sunward/Scenes/Windflower.unity and press Play.
