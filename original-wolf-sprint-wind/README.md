# Amaterasu — isolated Sprint polish

Open Amaterasu-Movement.blend in Blender 4.3+. Sprint_Polished is selected.
Press Space. See OPEN-IN-BLENDER.txt for selecting Actions and wind controls.

The previous Sprint is retained alongside Idle, Walk, Jog and Legacy_Run.
Original mesh, weights, rest rig, textures and wolf materials remain unchanged.
Only the new Action's head, two neck and five tail controls were authored.
Legs, toes, shoulders, hips and body retain the approved Sprint's exact curves.

Separate tapered, pigment-varied wind ribbons use native Blender drivers.
They appear on Sprint_Polished, and respond to an independent wind-speed control.
The optional Wind_Speed_Demo Action on the effect empty demonstrates a smooth
acceleration/fade; it does not change the wolf's animation or movement speed.
No Python auto-run or add-ons are needed when opening the delivered file.

This is a review candidate; the previous accepted project is not overwritten.
No game or browser-viewer files were modified. Source licence is included.
